# CONTEXT — Clief-Notes Challenges

This directory holds challenge specifications from the Clief-Notes Skool community weekly competitions.

## Routing

Each challenge subfolder (e.g., `comp-11-the-cartographer`) is self-contained:
- **`CHALLENGE.md`** — Requirements and submission details

There is no internal routing; each challenge stands alone as reference material.

These are example challenges, not active workspace tasks. See [../CONTEXT.md](../CONTEXT.md) — `clief-notes/` sits outside MWP routing entirely.
