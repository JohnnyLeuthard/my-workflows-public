# Clief-Notes Challenges Workspace

This directory contains weekly competition challenges from the Clief-Notes Skool community. Each challenge folder (e.g., `comp-01-`, `comp-02-the-artifact-sprint`) holds the challenge specification and supporting materials.

## Structure

Each challenge directory contains:
- `CHALLENGE.md` — Challenge requirements and submission guidelines
- Supporting materials (optional) — Results, examples, or reference docs

## Workflow

When setting up a new challenge:
1. Create a folder: `comp-XX-{challenge-name}`
2. Add `CHALLENGE.md` with requirements only (no comments)
3. Route through [CONTEXT.md](CONTEXT.md)

## Reference

Read [../CONTEXT.md](../CONTEXT.md) for how `clief-notes/` sits outside MWP routing. This workspace is read-only reference material; active project work does not route here.
